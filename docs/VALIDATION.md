## 本次公开版重新验证

- 自选音频与 GUI：13 项通过；默认无音频，兼容旧内置标识，主界面及任务编辑器均要求选择音频文件。

- 主页固定布局：22 项通过，检查无滚动、固定大小、三语言和三种时间模式、控件状态及文字完整可见。
- DPI 布局：100%、125%、150%、200%共 36 项通过，使用 Tk 缩放模拟检查，不能替代所有系统显示缩放实测。

- 系统监控和悬浮窗：34 项通过，包含真实采样、暂停同步、位置和导入校验。
- 最终公开 exe：29 项通过；版本、一体标题栏、固定尺寸、滚轮无位移、双屏拖动无黑条、置顶、任务中心、设置、常亮开关、监控、悬浮窗无独立任务栏条目、最小化恢复和无任务创建。

- PyInstaller 与 Inno Setup 编译成功；归档不包含 mp3/wav/flac/ogg 或 assets/audio，包含 MIT 与第三方声明。
- 源码归档、构建输入和发行文件使用哈希校验；公开文件白名单排除配置、日志、音频、虚拟环境、构建缓存和私有开发历史。

GUI 验证使用隔离 APPDATA，不创建真实电源任务；未执行关机、重启、注销、锁定、睡眠、休眠，未结束用户程序或修改用户亮度/音量。测试常亮请求最终释放，开机启动注册表值已保护和恢复。没有覆盖用户现有安装目录。
