# v2.0 验证范围

基于已通过用户本地测试的紫樱 R17。公开版保留其交互与视觉，另行恢复公开升级身份、改为 v2.0 名称并排除内置音乐后重新构建。

验证覆盖公开版音频选择、旧配置读取、身份及版本、公开资源扫描、100%／125%／150% 三档缩放、简体／繁体／英文设置、重复唤起、隐藏／最小化恢复、长任务滚动边框、保存与快捷键回归，以及最终 exe 启动和恢复。

GUI 测试仅使用临时配置和模拟硬件，不执行真实关机。Windows 10 x64 为实测环境；Windows 11 尚未实机验证。发布核验详情随维护目录保留，README 截图来自 v2.0 公开源码实际渲染。

本轮公开版共 1031 项检查通过，其中包括 52 项核心检查、公开版音频／迁移检查、三档缩放布局与窗口回归、保存及快捷键工作流，以及最终便携包启动恢复核验。63 个打包模块与源码一致，36 个资源逐一比对，无内置音频。
